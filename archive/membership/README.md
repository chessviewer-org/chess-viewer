# Archived membership and badges

The former donation tiers, sponsor badges and status-granting code are kept here
as comments at the project owner's request. Nothing in this directory is imported
or executed, and Tailwind excludes it from class detection.

Active donations use the wallet in the Donate page. They do not grant account
status, badges or benefits. `AvatarInitial` remains an ordinary profile component.

The current database schema retires `set_supporter_status` when applied. Existing
profile records are not deleted.
